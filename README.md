## ⚡ Quick Start

### Prerequisites

| Component | Version |
|---|---|
| Python | **3.11.x** (required for TensorFlow 2.21 compatibility) |
| RAM (Pi) | ≥ 4 GB |
| Storage | ≥ 500 MB free |

### 1. Set Up Isolated Environment
```bash
# Install uv (fast Python package manager)
curl -LsSf https://astral.sh/uv/install.sh | sh

# Create Python 3.11 virtual environment
uv venv .venv --python 3.11
source .venv/bin/activate        # Linux / Raspberry Pi
# .venv\Scripts\activate          # Windows PowerShell
```

### 2. Install Dependencies
```bash
uv pip install numpy scipy scikit-learn tensorflow matplotlib
# On Raspberry Pi, replace tensorflow with:
# uv pip install tflite-runtime numpy scipy matplotlib
```

### 3. Run Stages in Order

```bash
# Stage 1: Preprocessing & Index Extraction
python stage1_preprocess.py

# Stage 2: Train & Quantize 1D-CNN Model (requires TensorFlow)
python stage2_train_model.py

# Stage 3: Onboard Edge Inference & Semantic Encoding
python stage3_edge_inference.py

# Stage 4: Phase 4 — Deploy, Benchmark, ISS Sim & Test Reports
python stage4_deploy_validate.py
```

## 🧠 AI Model Specifications

| Attribute | Value |
|---|---|
| Architecture | 1D Convolutional Neural Network (1D-CNN) |
| Input Shape | `(204, 1)` — 204 spectral bands per pixel |
| Output Shape | `(16,)` — Salinas class probabilities |
| Training Accuracy | **~87.24%** on held-out validation set |
| Model Precision | `Float32` → quantized to **`INT8`** |
| Full Precision Size | 5,083 KB |
| Quantized Size (INT8) | **434 KB** (91.5% compression) |
| Format | TensorFlow Lite (`.tflite`) |
| Inference Speed (Pi 4B) | ~3.6 s / scene (KPI: < 30 s) ✅ |

## 🗺️ ClimCam Semantic Classes

The model output (16 Salinas classes) is remapped to **4 ClimCam mission domains**:

| Class ID | Domain | Salinas Classes Mapped | Color |
|---|---|---|---|
| 1 | 🌱 **Vegetation** | Broccoli, Celery, Grapes, Corn, Lettuce, Vineyard | Green |
| 2 | 💧 **Hydration** | Overrides via NDWI > 0.55 | Blue |
| 3 | 🏜️ **Desertification** | Fallow, Fallow Rough, Fallow Smooth | Gold |
| 4 | 🏢 **Urban** | Stubble, Soil Vineyard, Vertical Trellis | Gray |

## 🛰️ ISS Pass Simulation

The ISS orbital simulation uses **Two-Line Element (TLE)** data to compute the satellite's ground track and detect **overflight windows** above East African targets:

| Target | Coordinates |
|---|---|
| Egypt — Nile Delta | 30.80°N, 30.92°E |
| Egypt — Cairo Metro | 30.04°N, 31.24°E |
| Kenya — Nairobi | 1.29°S, 36.82°E |
| Kenya — Lake Victoria | 0.14°S, 37.08°E |
| Uganda — Kampala | 0.35°N, 32.58°E |
| Uganda — Lake Albert | 1.68°N, 31.15°E |

**Footprint Radius:** 500 km per ISS pass window  
**Priority:** HIGH (< 200 km), MEDIUM (200–500 km)

## 🚨 Alert System Thresholds

| Alert Type | Trigger Condition | Severity |
|---|---|---|
| `DESERTIFICATION_ENCROACHMENT` | Bare soil/desert > 28% of scene | ⚠️ WARNING |
| `ACUTE_MOISTURE_DEFICIT` | Mean NDWI < -0.10 OR Hydration < 8% | 🔴 CRITICAL |
| `VEGETATION_PATHOLOGY_RISK` | Mean NDRE < 0.12 with Vegetation > 20% | ⚠️ WARNING |
| `NOMINAL_CONDITIONS` | All indicators within safe ranges | ℹ️ INFO |

## 📋 API Reference

### `EdgeInferenceEngine`
```python
engine = EdgeInferenceEngine(model_path="outputs/hyperspectral_model_quantized.tflite")
pred_map, conf_map, elapsed = engine.predict(cube)
```

| Parameter | Type | Description |
|---|---|---|
| `model_path` | `str` | Path to `.tflite` INT8 quantized model |
| `chunk_size` | `int` | Pixels per inference batch (default: 2048) |

**Returns:** `(pred_map: ndarray[H,W], conf_map: ndarray[H,W], elapsed_seconds: float)`

---

### `ISSPassSimulator`
```python
sim = ISSPassSimulator(ISS_TLE)
passes = sim.find_passes_over_targets(targets, start_dt, duration_hours=24, footprint_radius_km=500)
```

| Parameter | Type | Description |
|---|---|---|
| `targets` | `List[Dict]` | List of `{"name", "lat", "lon"}` dicts |
| `start_dt` | `datetime` | Simulation start time (UTC) |
| `footprint_radius_km` | `float` | Sensor coverage radius from nadir point |

**Returns:** `List[Dict]` — Sorted list of overflight events with GPS, timestamp, priority
